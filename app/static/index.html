Самое горячее — прямо сейчас

Собираю тренды из Google Трендов, Google Новостей, YouTube, Reddit, Hacker News, Хабра, СМИ и Instagram, склеиваю их в темы и оцениваю «горячесть». Выберите тему — сделаю видео 1–30 минут с мужской озвучкой и отправлю в Telegram-канал.

🌐 Это версия сайта на GitHub Pages: тренды обновляются автоматически каждые 2 часа. Видео делаются в GitHub Actions и появляются справа, в блоке «Видео».

Как запустить (сайт статический, видео делает GitHub):
  1. Нажмите «Открыть запуск в GitHub» — откроется страница Actions (нужно войти в свой GitHub).
  2. Справа нажмите Run workflow.
  3. Вставьте в поле topic тему, в поле minutes — длительность:
topic
minutes
  1. Нажмите зелёную Run workflow. Через 5–15 минут ролик появится в блоке «Видео» на этом сайте (а если подключён Telegram-бот и стоит галочка publish — и в канале). Голос — мужской «Дмитрий».

Тема копируется в буфер обмена автоматически при нажатии кнопки.
